## ✨ المميزات الرئيسية (Core Features)

1. **تصميم Mobile-First بالكامل:**
   - شريط تنقل سفلي ثابت (`Bottom Navigation Bar`).
   - شريط سلة عائم ديناميكي (`Sticky Cart Bar`).
   - نوافذ منبثقة سفلية سلسة (`Bottom Sheets`) لاختيار الإضافات ومراجعة السلة وحجز الطاولات.
   - مساحات لمس مريحة (48px+ Touch Targets) ملائمة للاستخدام بيد واحدة على الهاتف.

2. **قائمة أطباق وتصنيفات تفاعلية:**
   - شريط تصنيفات أفقي مثبت مع بحث فوري سلس في الأطباق.
   - إمكانية تخصيص الأطباق مع درجات الاستواء والإضافات والصلصات.

3. **سلة طلبات ومحاكاة طلبات متطورة:**
   - دعم التوصيل للمناطق وحساب رسوم التوصيل أو الاستلام من الفرع.
   - إرسال تفاصيل الطلب مباشرة ومكتملة عبر واتساب إلى الرقم المعتمد.

4. **نظام حجز الطاولات:**
   - حجز مسبق مع تحديد عدد الضيوف، القسم (عوائل بخصوصية تامة، أفراد، جلسات خارجية)، والتاريخ والوقت مع كود حجز وتأكيد مباشر عبر واتساب.

5. **دعم كامل للغتين (Arabic RTL & English LTR):**
   - تبديل فوري بلمسة واحدة بدون إعادة تحميل الصفحة.

## 🚀 خطوات النشر على GitHub Pages

المشروع مصمم كـ **موقع ثابت (Pure Static Web App)** ويعمل مباشرة بدون الحاجة لأي خادم خلفي:
1. ارفع المشروع إلى مستودع GitHub الخاص بك:
   ```bash
   git add .
   git commit -m "Deploy Hamra Grills website"
   git push origin main
   ```
2. من إعدادات المستودع (**Settings**) -> انتقل إلى قسم **Pages**.
3. في خيار **Source** اختر: **Deploy from a branch**.
4. حدد الفرع `main` والمجلد `/ (root)` واضغط **Save**.
5. سيعمل الموقع مباشرة وبشكل متكامل مع جميع الصور والتنسيقات.
